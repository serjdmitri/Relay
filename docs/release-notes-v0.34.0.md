Faster answers, and a set of experimental features (off by default): command Relay by text, plugins, live panels, ask my notes, speak up on its own, offline mode.

## What changed
- **Faster answers** (on by default): no extended thinking, low Codex effort, parallel tool calls, fewer re-checks.
- **Experimental, off by default** (Settings > Doctor > Experimental; run Doctor first): command Relay by text and a queue while the Mac sleeps, plugins from GitHub or a folder (with an approval screen and a sandbox), live panels, ask my notes, speak up on its own.
- **Offline mode:** plain questions go to your local Ollama model when there is no internet.
- **Recent menu** opens only from its tab and is one liquid-glass shape.

Unit-tested only; none of it has run on a real Mac. If Relay does not open, run `npm start` and send the first error.

## Requirements
**macOS 26 or later.** Apple Silicon (`arm64`) and Intel (`x64`) builds are attached below.
